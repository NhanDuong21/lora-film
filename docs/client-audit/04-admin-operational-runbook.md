# Admin operational runbook

1. Login and open `/admin/movie-operations` for system readiness.
2. Review saved movie metadata under `/admin/movies`; TMDB review is optional and must degrade safely.
3. Review cinema, room and seat layout under facilities.
4. Configure/activate a complete price policy before creating or opening a showtime.
5. Use showtime schedules/preview, then confirm showtime pricing is `complete=true` before open sale.
6. Review concessions and promotions.
7. Monitor bookings, then open payment detail for the associated transaction.
8. Use analytics/HR/notification modules only after their route smoke checks pass.

Expected handoff between steps must be available through visible links/buttons; operators must not edit URLs or type technical IDs.
